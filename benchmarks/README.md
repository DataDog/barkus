# Barkus Reproducible Fuzzer Benchmark Suite

This directory holds the containerized benchmark used to compare Barkus
(structure-aware fuzz generator) against state-of-the-art fuzzers on real
systems-under-test. It backs the research paper described in
`/home/bits/.claude/plans/i-m-working-on-making-foamy-star.md` (the plan
file kept outside the repo to avoid coupling it to this codebase).

## Layout

```
benchmarks/
  PROGRESS.md                    # milestone tracker for the agentic loop
  docker/
    Dockerfile.base              # M1: pinned toolchains + Barkus FFI + smoke binary
    cbindgen.toml
    test-roundtrip.c             # M1 smoke binary (FFI sanity check)
  orchestrator/
    run.py                       # entry point: build / smoke / full / aggregate / report
    config.yaml                  # SUT × variant × dict × seed matrix
    schema.py                    # pydantic models for run.json + samples.jsonl
    collector.py                 # cell-level collector
    parsers/                     # per-engine output parsers
    requirements.in              # top-level Python deps
    requirements.lock            # hash-pinned, generated by pip-compile
  suts/                          # M3-M8 add SUT harnesses here
  fixtures/                      # ANTLR grammars-v4 submodule (M3+)
  results/                       # gitignored
  reports/                       # gitignored
```

## Reproducing a benchmark run

Every external dependency is SHA/version-pinned. Two runs at the same
git SHA install identical toolchains; only fuzzer PRNG draws differ.

```sh
# Build the base image (M1).
docker build -f benchmarks/docker/Dockerfile.base -t barkus-base:dev .

# Verify FFI smoke (M1 done-when).
docker run --rm barkus-base:dev /opt/barkus/test-roundtrip

# Set up orchestrator deps (M2).
python3 -m venv .venv
. .venv/bin/activate
pip install --require-hashes -r benchmarks/orchestrator/requirements.lock

# 60-second smoke gate (M2 self-test against fake engine; M3-M6 add real ones).
python benchmarks/orchestrator/run.py smoke --tier 0
```

## Regenerating the lockfile

Only when intentionally bumping a Python dep. Never edit `requirements.lock`
by hand.

```sh
pip install pip-tools==7.4.1
pip-compile --generate-hashes \
  --output-file benchmarks/orchestrator/requirements.lock \
  benchmarks/orchestrator/requirements.in
```

## Hard rules (paper-credibility)

These are encoded in `config.yaml` and `run.py` and must not be loosened:

- Cold-start corpus on every cell — `rm -rf` before launch.
- Auto-dictionary is a matrix axis (`dict={on,off}`), never disabled silently.
- Sanitizers off during timed runs; on only for the post-hoc crash-dedup pass.
- Same engine version, same engine flags across all variants of a SUT.
- Pre-register provenance (Barkus SHA, SUT SHA, grammar SHA, engine version)
  in `run.json` before the cell starts.
- Variance: 3 seeds is the floor; mean ± std-dev on every chart, never bare numbers.
